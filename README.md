# Jamals AI

Premium SAT & IELTS preparation platform with **Humo** (3D AI Tutor).

## Brand
- AI Tutor: **Humo** (golden metallic 3D bird of fortune)
- Design: Dark luxury (black + amber/gold)
- Target: Ambitious students preparing for university admissions

## Current Features
- Landing page
- Student Dashboard
- 3D Humo AI Tutor (side panel + chat)
- Filterable Question Bank
- Mock Tests
- Analytics
- Mistake Review
- Profile
- Mobile bottom navigation

## Run
```bash
pnpm install
pnpm dev
```
